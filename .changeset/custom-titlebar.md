Draw the window header ourselves on every platform. The toolbar now doubles as
the titlebar: it can be dragged to move the window and double-clicked to zoom,
and it reserves room for the traffic lights on macOS. Windows and Linux get
minimise, maximise and close buttons rendered in the bar, Linux uses client-side
decorations with resize handles along every edge, and right-clicking the header
opens the system window menu.
